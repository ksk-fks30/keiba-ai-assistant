# keiba-ai

個人利用のための競馬予想AIツール。

このプロジェクトは公開Webサービスではなく、指定したレースについてローカル環境でデータを取得し、ユーザー定義の予想方針に基づいて分析し、ブラウザで閲覧・追加質問できるローカルWebアプリとして開発する。

## 利用範囲

- 利用目的は個人の私的利用に限定する。
- 生成されたレースレポートはローカル閲覧のみを前提とする。
- 取得データ、生成HTML、ブラウザセッション、キャッシュ、スクリーンショットは公開・配布しない。
- 公開リポジトリに含めるのは、ソースコード、テンプレート、設定例、架空データのサンプルのみとする。

## データ取得方針

- 主データソースはnetKeibaとする。
- netKeibaの利用はグレー領域を含むため、ローカル私用・低頻度・低負荷を前提にする。
- ブラウザ操作によってページを開き、画面上の情報を構造化データとして取得する。
- CAPTCHA、ログイン、有料導線、アクセス制限を回避する実装は行わない。
- 通信制限、警告、異常レスポンスを検知した場合は取得を停止する。
- 天気情報はnetKeibaとは別の情報源から取得する。

## 取得対象

- レース場
- 距離
- 芝またはダート
- 出走馬一覧
- 各馬の過去走
- 血統
- 騎手
- 調教師
- 馬体重
- オッズ
- 天気

## アクセス制御

- 並列アクセスは行わない。
- ページ取得は1ページずつ順番に行う。
- ページ遷移ごとに待機時間を入れる。
- 待機時間は設定可能にする。
- 同じURLはキャッシュし、不要な再取得を避ける。
- 複数レースの一括巡回は行わない。
- 短時間に複数回のリクエストを発生させない。
- 失敗時のリトライ回数には上限を設ける。

## データ保存方針

- 取得データはローカルにのみ保存する。
- 生成HTMLはローカルにのみ保存する。
- `data/`、`reports/`、ブラウザ認証情報、キャッシュ、DBファイルはGit管理しない。
- netKeiba由来のHTML、画像、スクリーンショット、馬柱の再現データは保存・公開しない。

## 分析方針

- AIにWebページを直接読ませて予想させず、取得データを構造化してから分析する。
- AI分析にはCodex SDKを使用する。
- 分析はユーザー定義の予想方針を優先する。
- ユーザーの予想方針はコードに埋め込まず、Markdownなどの外部ファイルとして管理する。
- レポートは元データの転載ではなく、分析結果、評価理由、印、買い目候補を中心に構成する。

## 技術方針

- 実装言語はTypeScriptを基本とする。
- ローカルWebアプリはHono、Inertia.js、Reactを基本とする。
- HonoのInertia連携には`@hono/inertia`を使用する。
- AI分析には`@openai/codex-sdk`を使用する。
- ブラウザ操作にはPlaywrightを使用する。
- CLIにはTypeScriptで利用できるCLIライブラリを使用する。
- データモデルと構造化出力スキーマにはZodを使用する。
- レースページはサーバー側ルーティングからInertiaページとして描画する。
- API専用エンドポイントを増やしすぎず、画面遷移と表示データはサーバー駆動で扱う。
- キャッシュや中間データはJSONまたはSQLiteで扱う。

## UI方針

- 最終出力はローカルブラウザで閲覧するレースレポートとする。
- レポート画面から同じレースについて追加質問できるようにする。
- 追加質問への回答はCodex SDKで生成し、レース単位のQ&A履歴として保存する。
- レポートには取得元URL、取得日時、私的利用目的で生成された旨を記録する。
- レポートは外部公開、転載、配布を前提としない。
