# keiba-ai-assistant

個人利用のための競馬予想AIアシスタント。

指定したレースについてローカル環境で情報を取得し、ユーザー定義の予想方針に基づいて分析する。分析結果はローカルブラウザで閲覧でき、同じレースについて追加質問できる。

## 目的

- 競馬レースの予想に必要な情報を集約する。
- 取得した情報をもとに、ユーザーの予想方針に沿って分析する。
- レースごとの予想、評価理由、買い目候補をレポートとして確認する。
- 生成後のレポートに対して、追加の質問や再検討を行えるようにする。

## 利用範囲

- 利用目的は個人の私的利用に限定する。
- レースレポート、取得データ、分析結果はローカル閲覧のみを前提とする。
- 取得データ、生成レポート、ブラウザセッション、キャッシュ、スクリーンショットは公開・配布しない。
- 公開リポジトリに含めるのは、ソースコード、設定例、架空データのサンプルのみとする。

## 主な機能

- レースURLを指定して対象レースを登録する。
- ブラウザ操作によりレース情報を取得する。
- レース場、距離、芝/ダート、出走馬、過去走、血統、騎手、調教師、馬体重、オッズ、Open-Meteo由来の天気などを分析材料として扱う。
- ユーザーの予想方針をもとにAI分析を行う。
- AI分析は、ローカルPCに導入済みのCodex CLIとそのログイン状態を使用する。
- レースごとの予想レポートをローカルブラウザで閲覧する。
- レポート画面から同じレースについて追加質問する。
- 追加質問と回答の履歴をレース単位で保持する。

## 予想方針

ユーザーの予想方針は `policies/main.md` に記述する。

予想方針には、重視する観点、軽視する観点、距離適性や馬場適性の見方、血統の扱い、人気馬や穴馬の評価方針、買い目の考え方などを記述する。

## レースデータ

レースごとの実行結果は `runs/` に保存する。

```text
runs/
  <race-id>/
    race.json
    prediction.json
    qa.jsonl
    thread.json
    metadata.json
```

取得キャッシュやブラウザ関連の一時データは `data/` に保存する。

`runs/` と `data/` の中身はGit管理しない。

## CLI

ローカルCLIはルートから `pnpm keiba` で実行する。

```sh
pnpm keiba collect "<race-url>"
pnpm keiba predict "<race-url>"
pnpm keiba analyze <race-id>
pnpm keiba ask <race-id> "<question>"
pnpm keiba qa-history <race-id>
```

`predict` はレース取得、`race.json` 保存、AI分析、`prediction.json` 保存をまとめて実行する。
取得、AI構造化、天気取得、分析、保存などの長時間処理では、進捗が標準出力に表示される。
`collect` は既定でheadlessブラウザを使い、ブラウザ画面を見たい場合は `--show-browser` を指定する。

## 利用上の注意

- netKeibaからの情報取得は、ローカル私用・低頻度・低負荷を前提にする。
- CAPTCHA、ログイン、有料導線、アクセス制限を回避する実装は行わない。
- 通信制限、警告、異常レスポンスを検知した場合は取得を停止する。
- 短時間に複数回のリクエストを発生させない。
- 複数レースの一括巡回や大量取得は行わない。
- netKeiba由来のHTML、画像、スクリーンショット、馬柱の再現データは保存・公開しない。
